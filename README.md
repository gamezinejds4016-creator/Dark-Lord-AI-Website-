# Dark Lord — AI Study Bot (Mock-only)

This repository contains a minimal Vite + React demo for the "Dark Lord" AI Study Bot. It is intentionally local-first so students can try it quickly without creating accounts.

Important: This version runs in Mock-only mode and does not include any Groq or other external AI integrations. Mock mode returns helpful tutor-style responses so you can continue developing and testing without API keys.

Quick start

1. Install:

   npm install

2. Run the dev server:

   npm run dev

Notes

- The demo stores chats and attachments in localStorage.
- This build does not require any external AI keys. All AI responses are generated by a local mock provider.
- To add a real AI provider later, implement a secure server-side integration and store API keys in environment variables (never commit keys to the repo).
